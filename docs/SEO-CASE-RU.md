# Технический SEO: публичная страница Voxel Drop

Дмитрий Михайлов · 27 октября 2026 · собственный проект, не клиентский заказ.

## Задача

Подготовить публичную страницу игры к обнаружению поисковыми роботами: определить основной URL и согласовать canonical, robots.txt и sitemap.xml. Работа выполнена на собственном Next.js-проекте, без материалов заказчиков под NDA.

## Фактическое состояние до изменений

Скрипт прочитал серверный HTML главной и HTTP-ответы ещё трёх адресов. Главная отвечала 200, содержала title, description и lang; директива noindex отсутствовала. Указатель canonical не был задан, robots.txt и sitemap.xml отвечали 404. Намеренно отсутствующая страница корректно возвращала 404.

Исходный снимок: [before.json](seo/before.json), 6 из 9 проверок. Для одностраничной игры отсутствие robots/sitemap само по себе не доказывает проблему индексации. Это ограниченный аудит базовой настройки обнаружения, а не заявление о критическом SEO-дефекте.

## Что изменено

| Элемент | Реализация | Проверенный результат |
| --- | --- | --- |
| Canonical | Next.js Metadata API, metadataBase и alternates.canonical | Один абсолютный canonical главной |
| robots.txt | Типизированный маршрут app/robots.ts | HTTP 200, Allow: /, ссылка на sitemap |
| sitemap.xml | Типизированный маршрут app/sitemap.ts | HTTP 200, единственный публичный URL |

В sitemap не добавлены вымышленные страницы, даты обновления и языковые URL. Английский и русский интерфейсы работают на одной странице; переключатель языка не выдаётся за мультиязычное SEO с hreflang.

## Повторная проверка

[after.json](seo/after.json): 9 из 9 базовых проверок на опубликованном сайте. Проверены статус главной, серверные title/description/lang, единственный self-canonical, отсутствие noindex в meta/X-Robots-Tag, robots со ссылкой на sitemap, sitemap с главной и реальный 404.

9/9 - результат конкретного скрипта, а не SEO-рейтинг. Разборщик проверяет реальные HTML-теги, не строки внутри JavaScript. В проверке canonical учтена эквивалентность корневого URL со слешем и без него. Первичная слишком строгая проверка слеша давала ложное отрицание; её исправили и проверили отдельными тестами до оформления результата. Это изменение анализатора не меняет вывод исходного снимка: до исправлений canonical отсутствовал.

## Как повторить

Нужен Python 3, сторонние библиотеки не требуются:

```sh
python tools/audit_seo.py https://voxel-drop-3d.vercel.app/ --output audit.json
python -m unittest discover -s tools -p test_audit_seo.py
```

Скрипт ограничен одной страницей, robots.txt, sitemap.xml и одним отсутствующим адресом. Он не сканирует всё пространство ссылок и не подтверждает фактический обход или индексацию.

## Практический результат и границы

Публичный сайт имеет согласованные служебные URL и основной адрес страницы; изменения можно воспроизвести по исходникам и JSON-снимкам. Локальные проверки типов, сборка и тесты проекта прошли; Vercel успешно развернул изменение b40936c.

Доступ к Search Console не использовался. Трафик, позиции, выручка и скорость загрузки не измерялись. Sitemap, robots и отсутствие noindex не гарантируют индексацию. Проверки производительности, семантики и большой мультиязычной структуры потребуют отдельного объёма.
