# Техническое задание: Voxel Drop 3D

## Цель

Создать production-ready веб-игру с объёмным полем 8×8×8. Игрок перемещает и вращает тетромино из четырёх вокселей, заполняет горизонтальные плоскости и набирает очки. Камера свободно вращается, но гравитация всегда направлена по мировой оси −Y.

## Объём первой версии

- Полный цикл: создание фигуры → управление → падение → фиксация → очистка слоя → следующая фигура.
- Семь классических тетромино и детерминированный 7-bag.
- Повороты вокруг X, Y и Z с ограниченными wall-kick компенсациями.
- Режимы Focus/Hardcore, старт без активного таймера, ghost-проекция, soft/hard drop, счёт, уровни, пауза, рестарт и game over.
- События фиксации и очистки слоя представлены в snapshot движка и используются UI для независимой анимации и отображения начисленных очков.
- Светлая и тёмная палитры автоматически синхронизируются с `prefers-color-scheme`; CSS-токены оформляют интерфейс, а отдельная typed-палитра — WebGL-сцену.
- Клавиатура, мышь, touch и адаптивный интерфейс.
- Автопауза при скрытии вкладки и reduced-motion режим.

## Архитектурные требования

- FSD: маршруты и providers → widgets → features → entities → shared.
- Импорты слайсов только через публичный `index.ts`.
- Игровое ядро — чистый TypeScript без React, Three.js и browser API.
- UI отправляет намерения движку и отображает неизменяемый snapshot.
- Композиция вместо иерархий наследования; фигуры описываются данными.
- Фиксированный simulation tick; случайность только через seeded generator.

## Производительность

- Цель: 60 FPS desktop, не менее 30 FPS на поддерживаемом mobile.
- Воксели поля рендерятся через `InstancedMesh` с общей геометрией и материалом.
- Pixel ratio ограничен значением 1.7.
- React не обновляется каждый animation frame: snapshot публикуется только при изменении симуляции.
- 3D-виджет загружается отдельным клиентским модулем.

## Критерии приёмки

- Игра запускается и управляется на desktop и mobile.
- Фигуры не выходят за границы и не пересекают занятые клетки.
- Полные горизонтальные слои удаляются атомарно.
- Одинаковый seed создаёт одинаковую очередь фигур.
- TypeScript, lint, unit-тесты и production build проходят без ошибок.
- Основная ветевая логика игрового ядра покрыта автоматическими тестами.

## За рамками v1

Аккаунты, серверный leaderboard, multiplayer, PWA/offline, звук, hold, replay UI, переназначение клавиш и WebGPU. Архитектура не блокирует их добавление, но они требуют отдельных продуктовых решений и тестирования.
